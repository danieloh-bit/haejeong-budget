# 해정이 가계부 PWA v1.1.1 — 달력 흰 화면 수정

원인: app.js 초기 상태에서 `today()`를 호출했지만, `today`는 그 아래 `const`로 선언되어 초기화 전 접근 오류(ReferenceError)가 발생했습니다. 날짜 함수 선언 후 달력 날짜를 초기화하도록 수정했습니다.

- 기존 localStorage 키 `haejeong-budget-pwa-v1` 유지. 거래 기록, D-Day, 예산, 백업 구조 변경 없음.
- 캐시 이름 변경으로 업데이트 시 구버전 캐시 정리.
- ZIP을 풀어 저장소 최상위에 파일과 assets 폴더를 업로드하고 기존 파일 덮어쓰기 → Commit changes → Pages 배포 완료 확인.
- 아이폰 앱 및 Safari 데이터 삭제 금지. 업데이트 전 가능한 경우 JSON 백업.
