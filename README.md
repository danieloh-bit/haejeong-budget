# 해정이 가계부 ❤️ — 무료 PWA

기존 iOS v11.7.4 디자인·기능을 참고하여 별도로 만든 웹앱입니다. SwiftUI 앱을 그대로 실행하는 것이 아니며, 기존 iPhone 앱의 UserDefaults 기록은 자동 이전되지 않습니다. 원본 앱의 백업 JSON 형식과 이 웹앱의 JSON 형식이 다를 수 있으므로 원본 백업은 그대로 복원된다고 보장하지 않습니다.

## 설치
1. 이 폴더의 파일 전체를 GitHub Pages, Cloudflare Pages 또는 다른 HTTPS 정적 호스팅에 올립니다. `index.html`만 단독으로 열면 오프라인 기능/홈 화면 설치가 제대로 작동하지 않습니다.
2. 아이폰 Safari에서 게시된 HTTPS 주소를 열고 공유 버튼 → 홈 화면에 추가를 누릅니다.
3. 홈 화면의 키티 아이콘으로 실행합니다. 최초 접속과 업데이트 시 인터넷이 필요할 수 있고, 최초 접속 후 정적 리소스가 캐시되면 오프라인에서도 사용할 수 있습니다.

## 기능
수입·지출 등록/수정/삭제, 월별 내역, 카테고리별 통계, 월/카테고리 예산, 홈 카테고리 바로 등록, D-Day, 카테고리 표시 설정, JSON 다운로드/복원/복사, 홈 화면 아이콘, 오프라인 캐시.

## 중요
- 데이터는 설치된 웹앱의 로컬 저장소에 보관됩니다. Safari 기록/웹사이트 데이터 삭제, 홈 화면 웹앱 삭제, 기기 분실, 저장소 정리 시 데이터가 유실될 수 있습니다. 정기적으로 백업 파일을 파일 앱/iCloud Drive 등에 별도 보관하세요.
- **기존 SwiftUI 앱 데이터는 자동 이전되지 않습니다.** JSON 구조를 확인해 변환해야 합니다.
- 배포용 Hello Kitty 캐릭터 이미지의 이용 권한은 별도로 확인하세요. 공개 호스팅은 URL을 아는 사람이 접속할 수 있습니다. 가계부 기록은 서버에 업로드하지 않지만 앱의 정적 파일은 공개될 수 있습니다.
- iOS/Safari의 정책 변화나 호스팅 서비스 운영에 따라 영구 사용이 보장되지는 않습니다. Apple 개발자 서명 7일 제한은 없습니다.


## v1.1 달력 기능 업데이트
- 홈의 **달력 보기** 또는 내역의 **달력** 버튼을 누르세요.
- 월 이동, 날짜 선택, 날짜별 수입·지출 표시, 선택 날짜 거래 수정, 선택 날짜 신규 등록을 지원합니다.
- 기존 localStorage 키 `haejeong-budget-pwa-v1`과 백업 JSON 구조를 변경하지 않았습니다. 기존 기록과 D-Day는 유지되도록 설계했습니다.
- GitHub 저장소의 최상위에서 `index.html`, `app.js`, `style.css`, `sw.js` 등을 **교체**하고 `assets` 폴더도 그대로 유지하세요. 압축파일이나 상위 폴더 자체를 업로드하지 마세요.
- 업데이트 전에 앱 설정에서 JSON 백업을 받아 두세요. 아이폰에서 기존 홈 화면 웹앱을 삭제하거나 Safari 웹사이트 데이터를 지우지 마세요.
- 서비스 워커 캐시 버전을 올리고 온라인일 때 최신 파일을 우선 요청하도록 수정했습니다. 배포 후 앱을 종료했다 다시 열면 새 버전이 반영됩니다.
